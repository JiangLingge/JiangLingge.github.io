十二、常用 front-matter 字段

字段 作用
title 文章标题
date / updated 创建时间 / 更新时间
tags / categories 标签（可多个）/ 分类（有层级）
description 摘要，首页和搜索结果显示
cover 首页封面图
top_img 文章顶部大图，false 表示不要
comments 本篇是否显示评论
sticky 置顶权重，数字越大越靠前
toc 本篇是否显示目录
katex / mermaid 是否加载公式 / 图表

最后

配置项不用一次全改完，用到哪个改哪个。真正决定博客好不好看的，其实是封面图和写作质量，而不是把每个开关都调一遍。

官方文档写得很细，遇到没列的选项直接查：https://butterfly.js.org/。
